# Подписки — трекер подписок для iPhone

Веб-приложение (PWA) для учёта подписок. Его можно установить на экран «Домой» iPhone, и дальше оно работает как обычное приложение, в том числе без интернета.

- Ручной ввод подписок: сумма, валюта (₽, $, €, ₸), дата платежа, периодичность, категория, статус, заметки, ссылка на сайт.
- Логотип подписки подставляется с сайта по ссылке: сервер ищет самую чёткую иконку (SVG, apple-touch-icon, manifest), запасной вариант — значок Google. Можно загрузить свою картинку.
- Автоматический расчёт даты следующего платежа. 31-е число в коротком месяце переносится на последний день месяца.
- **Лампочка у каждой подписки**:
  - 🟢 зелёная — до платежа больше 3 дней;
  - 🟡 жёлтая — осталось 3 дня или меньше;
  - 🔴 красная — платёж просрочен;
  - ⚪ серая — подписка на паузе или отменена.
- Кнопка **«Оплачено»** переводит подписку на следующий период. Ошибочное нажатие отменяется кнопкой «Отменить» во всплывающем сообщении.
- Главная карточка: траты в месяц и в год в рублях, число просроченных платежей. Доллары, евро и тенге пересчитываются по курсу ЦБ (курс берётся с cbr-xml-daily.ru и хранится на устройстве). Суммы можно скрыть кнопкой с глазом.
- Карточка «Ближайший платёж».
- Готовые сервисы в форме: одно нажатие подставляет название, сайт и категорию.
- Поиск по названию, категории и заметкам (появляется от шести подписок).
- Пробный период: дата окончания, метка в списке и напоминание накануне.
- История: отмеченные оплаты и прошлые цены хранятся в подписке и видны в её форме.
- Экран «Статистика» (меню аватара): оплачено за месяц и год, круговая диаграмма по категориям, подсказки.
- Счётчик просроченных платежей на иконке приложения (iOS 16.4+).
- Фильтры по категории (круглые аватары) и по статусу: стеклянная панель вкладок снизу, как в Telegram. Линзу можно вести пальцем.
- Окна закрываются свайпом вниз за полоску сверху.
- Свайп строки влево открывает кнопку удаления, вправо — отметку «Оплачено»; длинный свайп срабатывает сразу.
- **Пуш-уведомления** о платежах (нужен сервер уведомлений, см. ниже).
- Экспорт в календарь (`.ics`) с напоминаниями: для одной подписки или для всех сразу.
- Резервная копия данных (JSON) и восстановление из неё.

## Дизайн

Тёмная OLED-тема в стиле финансовых приложений iOS:

- чёрный фон `#000`, плоские карточки `#1C1C1E` с тонкой рамкой, без теней;
- шрифт SF Pro, крупные суммы и заголовки — SF Pro Rounded;
- акценты по смыслу: пастельный персик `#FFB4A2` — кнопки и выбранное, зелёный `#30D158` — включено, красный `#FF453A` — просрочка;
- карточка ближайшего платежа с малиново-персиковым градиентом;
- плавающие элементы из Liquid Glass: верхняя и нижняя панели, кнопка «+», меню, модальные окна, всплывающие сообщения.

Токены лежат в `src/styles/tokens.css`.

## Установка на iPhone

1. Откройте адрес приложения в **Safari**, например `https://<ваш-логин>.github.io/subscription-tracker/`.
2. Нажмите «Поделиться» (квадрат со стрелкой вверх).
3. Выберите «На экран «Домой»» и нажмите «Добавить».

Приложение откроется на весь экран со своей иконкой. После первого запуска оно работает без интернета.

## Как пользоваться

**Дата платежа.** Укажите дату первого или последнего списания. Следующие даты приложение посчитает само.

**«Оплачено».** Дата платежа не сдвигается сама. Когда до списания остаётся 3 дня или платёж уже просрочен, в строке появляется кнопка «Оплачено». Одно нажатие отмечает один платёж. Если пропущено несколько периодов, нажмите кнопку несколько раз. При добавлении подписки все прошлые платежи считаются оплаченными. Из формы подписки оплату можно отметить и заранее.

**Напоминания.** В подписке выберите, за сколько дней напомнить (1, 3, 7, 14 или своё число). Напоминание приходит одним из двух способов.

*Пуш-уведомления.* Работают на iPhone с iOS 16.4 или новее, только в приложении, открытом с экрана «Домой».

1. Нажмите колокольчик в правом верхнем углу.
2. Включите «Пуш-уведомления» и разрешите уведомления в системном окне.
3. Проверьте кнопкой «Отправить тестовое уведомление».

Уведомление приходит в 10:00 по времени телефона. Расписание на 120 дней вперёд обновляется на сервере при каждом изменении подписок и при открытии приложения. Для этого на сервер уведомлений уходят название, сумма и дата ближайших платежей; сами подписки остаются на устройстве.

*Календарь.* Работает без интернета и сервера.

1. Нажмите значок календаря в строке подписки или «Все подписки в календарь» в окне колокольчика.
2. На iPhone откроется меню «Поделиться». Выберите «Календарь». Если его нет, выберите «Сохранить в Файлы», затем откройте файл в приложении «Файлы» и нажмите «Добавить все».

Файл `.ics` также открывается в Google Календаре и Outlook.

**Резервная копия.** Данные хранятся только на устройстве. iOS удаляет их, если удалить иконку приложения с экрана «Домой». Периодически делайте копию: кнопка с аватаром слева вверху → «Сохранить копию» (удобно сохранить в iCloud Drive). Чтобы вернуть данные: аватар → «Восстановить из копии».

## Разработка

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install        # установка зависимостей
npm run dev        # dev-сервер: http://localhost:5173
npm run build      # проверка TypeScript и сборка в dist/
npm run preview    # просмотр собранной версии
npm test           # unit-тесты (Vitest), включая тесты сервера уведомлений
npm run lint       # линтер (oxlint)
npm run icons      # пересоздать иконки из public/icon.svg
```

Чтобы открыть dev-сервер на iPhone в той же Wi‑Fi-сети, запустите `npm run dev -- --host` и откройте адрес из строки `Network`. По http без https service worker не работает: для офлайна, установки и пушей нужна опубликованная версия.

## Публикация на GitHub Pages

Сборка и публикация настроены в `.github/workflows/deploy.yml` и запускаются при каждом push в ветку `main`.

1. Создайте на GitHub **публичный** репозиторий `subscription-tracker`. Бесплатный GitHub Pages работает только с публичными репозиториями.
2. В репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
3. Отправьте код:
   ```bash
   git remote add origin https://github.com/<ваш-логин>/subscription-tracker.git
   git push -u origin main
   ```
4. Дождитесь зелёной галочки на вкладке **Actions**. Сайт будет доступен по адресу `https://<ваш-логин>.github.io/subscription-tracker/`.

Путь сайта (`/subscription-tracker/`) workflow передаёт в сборку через переменную `BASE_PATH`.

## Сервер уведомлений

GitHub Pages отдаёт только статические файлы, поэтому пуши отправляет отдельный сервер: Cloudflare Worker из папки `worker/`. Хватает бесплатного тарифа.

- `POST /api/subscribe` — принимает подписку Web Push и расписание напоминаний устройства.
- `DELETE /api/subscribe` — удаляет устройство.
- `POST /api/test` — тестовое уведомление, не чаще раза в минуту.
- `GET /api/logo?host=` — самая чёткая иконка сайта для логотипа подписки (кэш на неделю).
- Cron раз в 15 минут отправляет напоминания, чьё время пришло. Если пуш-сервис отвечает, что подписки больше нет, устройство удаляется.

Сервер принимает запросы только с сайтов из `ALLOWED_ORIGINS` и только адреса пуш-сервисов Apple, Google, Mozilla и Microsoft.

### Первый запуск

Нужен аккаунт Cloudflare. Команды выполняются в папке `worker/`.

1. Установите зависимости и войдите в Cloudflare:
   ```bash
   npm install
   npx wrangler login
   ```
2. Создайте базу и вставьте её `database_id` в `wrangler.jsonc`:
   ```bash
   npx wrangler d1 create subscription-push
   ```
3. Создайте таблицы:
   ```bash
   npm run db:migrate
   ```
4. Сгенерируйте VAPID-ключи. Приватный ключ никуда не коммитьте:
   ```bash
   node scripts/generate-vapid-keys.mjs
   ```
5. Сохраните оба ключа в секреты сервера (команда попросит вставить значение):
   ```bash
   npx wrangler secret put VAPID_PUBLIC_KEY
   npx wrangler secret put VAPID_PRIVATE_KEY
   ```
6. Опубликуйте сервер. Команда выведет адрес вида `https://subscription-push.<аккаунт>.workers.dev`:
   ```bash
   npm run deploy
   ```
7. В корне репозитория создайте `.env.production` с публичными значениями и отправьте его в `main`:
   ```
   VITE_PUSH_API_URL=https://subscription-push.<аккаунт>.workers.dev
   VITE_VAPID_PUBLIC_KEY=<публичный ключ>
   ```

Если сайт живёт не на `ussuqpussu.github.io`, поменяйте `ALLOWED_ORIGINS` и `VAPID_SUBJECT` в `wrangler.jsonc`. Без `.env.production` приложение собирается как раньше: переключатель пушей скрыт, остаются напоминания через календарь.

Локально: создайте `worker/.dev.vars` с `VAPID_PUBLIC_KEY` и `VAPID_PRIVATE_KEY`, выполните `npm run db:migrate:local` и `npm run dev`. Cron запускается запросом `curl "http://localhost:8787/__scheduled"`.

## Структура

```
src/
  App.tsx                    — экран, состояние и обработчики действий
  sw.ts                      — service worker: офлайн-кэш и показ пушей
  types.ts, constants.ts     — модель данных и справочники
  state/subscriptionsReducer.ts — изменения списка подписок
  hooks/useLocalStorage.ts   — состояние с сохранением в localStorage
  hooks/useToday.ts          — «сегодня», обновляется после полуночи
  hooks/usePushSync.ts       — отправка расписания пушей на сервер
  utils/dateUtils.ts         — расчёт дат платежей
  utils/subscriptionUtils.ts — лампочки, сортировка, фильтры, суммы, история
  utils/stats.ts             — доли категорий, фактические траты, подсказки
  utils/rates.ts, hooks/useRates.ts — курсы ЦБ и траты в рублях
  utils/logo.ts, logoImage.ts — ссылки, значки сайтов, свой логотип
  utils/pushReminders.ts     — расписание пуш-напоминаний
  utils/push.ts              — подписка Web Push и запросы к серверу
  utils/icsUtils.ts          — генерация .ics (RFC 5545)
  utils/backup.ts            — резервная копия
  utils/subscriptionSchema.ts, validation.ts — проверка данных и формы
  utils/fileShare.ts         — меню «Поделиться» или скачивание файла
  utils/format.ts            — Intl-форматирование для ru-RU
  components/                — компоненты интерфейса и их CSS-модули
  styles/                    — токены, базовые стили, карточки, Liquid Glass
worker/                      — сервер уведомлений (Cloudflare Worker + D1)
public/                      — иконки приложения
```

Тесты лежат рядом с кодом: `src/utils/*.test.ts`, `worker/src/*.test.ts`.

## Ограничения

- Нет синхронизации между устройствами: данные живут в `localStorage` конкретного браузера. Переносите их через резервную копию.
- Пуши требуют сервера и приходят только в установленное на «Домой» приложение. Если не открывать приложение дольше 120 дней, расписание закончится.
- Эффект стекла сделан на CSS: размытие, насыщенность и блики. Настоящее преломление фона (как в iOS 26) в Safari через веб недоступно.
