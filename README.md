# Подписки — трекер подписок для iPhone

Веб-приложение (PWA) для учёта подписок. Его можно установить на экран «Домой» iPhone, и дальше оно работает как обычное приложение, в том числе без интернета.

- Ручной ввод подписок: сумма, валюта (₽, $, €, ₸), дата платежа, периодичность, категория, статус, заметки.
- Автоматический расчёт даты следующего платежа. 31-е число в коротком месяце переносится на последний день месяца.
- **Лампочка у каждой подписки**:
  - 🟢 зелёная — до платежа больше 3 дней;
  - 🟡 жёлтая — осталось 3 дня или меньше;
  - 🔴 красная — платёж просрочен;
  - ⚪ серая — подписка на паузе или отменена.
- Кнопка **«Оплачено»** переводит подписку на следующий период. Ошибочное нажатие отменяется кнопкой «Отменить» во всплывающем сообщении.
- Сводка трат в месяц по каждой валюте и число просроченных платежей.
- Фильтры по статусу и категории.
- Экспорт в календарь (`.ics`) с напоминаниями: для одной подписки или для всех сразу.
- Резервная копия данных (JSON) и восстановление из неё.
- Дизайн в стиле iOS с эффектом Liquid Glass, светлая и тёмная тема.

## Установка на iPhone

1. Откройте адрес приложения в **Safari**, например `https://<ваш-логин>.github.io/subscription-tracker/`.
2. Нажмите «Поделиться» (квадрат со стрелкой вверх).
3. Выберите «На экран «Домой»» и нажмите «Добавить».

Приложение откроется на весь экран со своей иконкой. После первого запуска оно работает без интернета.

## Как пользоваться

**Дата платежа.** Укажите дату первого или последнего списания. Следующие даты приложение посчитает само.

**«Оплачено».** Дата платежа не сдвигается сама. Когда до списания остаётся 3 дня или платёж уже просрочен, в строке появляется кнопка «Оплачено». Одно нажатие отмечает один платёж. Если пропущено несколько периодов, нажмите кнопку несколько раз. При добавлении подписки все прошлые платежи считаются оплаченными. Из формы подписки оплату можно отметить и заранее.

**Напоминания.** Выберите, за сколько дней напомнить (1, 3, 7, 14 или своё число). Напоминания срабатывают в системном календаре после экспорта:

1. Нажмите значок календаря в строке подписки (или «…» → «Все в календарь»).
2. На iPhone откроется меню «Поделиться». Выберите «Календарь». Если его нет, выберите «Сохранить в Файлы», затем откройте файл в приложении «Файлы» и нажмите «Добавить все».

Файл `.ics` также открывается в Google Календаре и Outlook.

**Резервная копия.** Данные хранятся только на устройстве. iOS удаляет их, если удалить иконку приложения с экрана «Домой». Периодически делайте копию: «…» → «Сохранить копию» (удобно сохранить в iCloud Drive). Чтобы вернуть данные: «…» → «Восстановить из копии».

## Разработка

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install        # установка зависимостей
npm run dev        # dev-сервер: http://localhost:5173
npm run build      # проверка TypeScript и сборка в dist/
npm run preview    # просмотр собранной версии
npm test           # unit-тесты (Vitest)
npm run lint       # линтер (oxlint)
npm run icons      # пересоздать иконки из public/icon.svg
```

Чтобы открыть dev-сервер на iPhone в той же Wi‑Fi-сети, запустите `npm run dev -- --host` и откройте адрес из строки `Network`. По http без https service worker не работает: для офлайна и установки нужна опубликованная версия.

## Публикация на GitHub Pages

Сборка и публикация настроены в `.github/workflows/deploy.yml` и запускаются при каждом push в ветку `main`.

1. Создайте на GitHub **публичный** репозиторий `subscription-tracker`. Бесплатный GitHub Pages работает только с публичными репозиториями.
2. В репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
3. Отправьте код:
   ```bash
   git remote add origin https://github.com/<ваш-логин>/subscription-tracker.git
   git push -u origin main
   ```
4. Дождитесь зелёной галочки на вкладке **Actions**. Сайт будет доступен по адресу `https://<ваш-логин>.github.io/subscription-tracker/`.

Путь сайта (`/subscription-tracker/`) workflow передаёт в сборку через переменную `BASE_PATH`.

## Структура

```
src/
  App.tsx                    — экран, состояние и обработчики действий
  types.ts, constants.ts     — модель данных и справочники
  state/subscriptionsReducer.ts — изменения списка подписок
  hooks/useLocalStorage.ts   — состояние с сохранением в localStorage
  hooks/useToday.ts          — «сегодня», обновляется после полуночи
  utils/dateUtils.ts         — расчёт дат платежей
  utils/subscriptionUtils.ts — лампочки, сортировка, фильтры, суммы
  utils/icsUtils.ts          — генерация .ics (RFC 5545)
  utils/backup.ts            — резервная копия
  utils/subscriptionSchema.ts, validation.ts — проверка данных и формы
  utils/fileShare.ts         — меню «Поделиться» или скачивание файла
  utils/format.ts            — Intl-форматирование для ru-RU
  components/                — компоненты интерфейса и их CSS-модули
  styles/                    — токены, базовые стили, материал Liquid Glass
public/                      — иконки приложения
```

Тесты лежат рядом с кодом: `src/utils/*.test.ts`.

## Ограничения

- Нет синхронизации между устройствами: данные живут в `localStorage` конкретного браузера. Переносите их через резервную копию.
- Push-уведомления без сервера невозможны, поэтому напоминания работают через календарь.
- Эффект стекла сделан на CSS: размытие, насыщенность и блики. Настоящее преломление фона (как в iOS 26) в Safari через веб недоступно.
